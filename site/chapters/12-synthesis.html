Chapter 12 · Synthesis

Nine tabs, one recipe

Validate, build a details object, wrap, sign, encode. If you can say that sentence with the right details class and flags, you can add a tab.

FIGURE 12.1 · The whole app in one grid.

The mental model

Every tab does the same four things: validate input, build a details object, wrap it in a GenericRequest, sign and encode. What differs is only which details object and which flags — and, in two cases, that more than one detail is needed.

A working sketch for a new tab

// routes/requests/myThing.ts
import { MyThingRequestDetails, MyThingRequestOrdinalVDXFObject } from "verus-typescript-primitives";
import { buildGenericRequestFromDetails, signRequest, getRpcConfig,
         requireString, parseRedirectsField } from "../utils";

export async function generateMyThingQr(req, res) {
  try {
    const signingId = requireString(req.body.signingId, "signingId");
    const redirects = parseRedirectsField(req.body.redirects);
    const { rpcHost, rpcPort, rpcUser, rpcPassword, isTestnet } = getRpcConfig();

    const details = new MyThingRequestDetails({ /* form fields */ });

    const request = buildGenericRequestFromDetails({
      details: [new MyThingRequestOrdinalVDXFObject({ data: details })],
      signed: true, signingId, redirects
    }, isTestnet);

    await signRequest({ request, rpcHost, rpcPort, rpcUser, rpcPassword, signingId });

    const deeplink = request.toWalletDeeplinkUri();
    res.json({ deeplink, qrDataUrl: await QRCode.toDataURL(deeplink) });
  } catch (e) {
    res.status(e.name === "ValidationError" ? 400 : 500).json({ error: e.message });
  }
}

Then mount it in server.ts and add a form view. That is genuinely the whole recipe; the rest of each route file is validation and the odd workaround.

The five lessons worth carrying

  • Sign the bytes you send. getRawDataSha256(false) before signatureAsVch is set, every time.
  • Ordering is semantic. Auth details go first when a constraint must be enforced.
  • Flags are the API. A request's meaning lives in its flag bits; set them from the fields, never the other way round.
  • Silent drops are the enemy. Unknown redirect types and ignored flags produce requests that look fine and fail later — validate in the route.
  • Round-trip when it matters. The encryption tab parses its own deeplink back and verifies the signature; nothing else does, and that is why it is the one that never ships a broken QR.
If you can describe a tab as "a details class plus flags, fed through two shared functions", you can build it in an afternoon.
